# Mac-GPU-Dash-TDH

**Mac-GPU-Dash-TDH** is a powerful and lightweight tool designed for measuring CPU and GPU performance metrics on macOS. Built with **Rust**, **Vite**, and **TypeScript**, this software provides real-time insights into system performance, leveraging **InstantDB** as its backend.

## Features

- ⚡ **Real-time Monitoring** – Track CPU and GPU usage seamlessly.
- 🖥️ **Modern UI** – Fast and responsive interface built with Vite and TypeScript.
- 🚀 **High Performance** – Optimized using Rust for speed and efficiency.
- 📊 **Instant Data Storage** – Uses InstantDB for quick and persistent data management.
- 🍏 **MacOS Support** – Specifically tailored for macOS systems.

## Tech Stack

- **Frontend**: Vite, TypeScript, React
- **Backend**: Rust, InstantDB
- **State Management**: Zustand (if applicable)

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/VijayMakkad/mac-gpu-dash-tdh.git
   cd mac-gpu-dash-tdh
   ```

2. Install dependencies:
   ```sh
   pnpm install
   ```

3. Start the backend server:
   ```sh
   cargo run
   ```

4. Start the frontend:
   ```sh
   pnpm dev
   ```

## Usage

- Open the application on macOS.
- Monitor real-time CPU and GPU performance.
- View historical performance data stored in InstantDB.
